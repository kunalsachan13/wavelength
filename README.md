# Wavelength 🌊

> **Your Music. Amplified.**  
> Stream high-fidelity audio, discover independent artists, and experience real-time waveform visualization.

---

## ✨ Features

- **High-Fidelity Audio Streaming**: Stream high-quality audio seamlessly.
- **Dynamic Waveform Visualizer**: Interactive real-time canvas waveform and ambient glow effects.
- **Rich Music Discovery**: Browse trending tracks, featured artists, curated playlists, and genre tags.
- **Creator Hub & Direct Support**: Artist profiles with direct tips/donations and upload workflows.
- **Full Player Suite**: Persistent mini player, expandable full-screen player, queue management, volume control, and repeat/shuffle modes.
- **Personalized Library**: Liked songs, custom playlists, listening history, and downloaded offline tracks.

---

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend API**: Python FastAPI / SpotAPI microservice

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [Python 3.10+](https://python.org/) (for API service)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kunalsachan13/wavelength.git
   cd wavelength
   ```

2. **Install frontend dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Create a `.env.local` file in the root directory:
   ```env
   VITE_SPOTAPI_URL=http://localhost:5000
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
